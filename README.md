# HCW Workspace Layout Prototype

A standalone layout study for the cellular-automata factory game's pseudo-desktop.

It deliberately tests the workspace shell before the game is coupled into it: launching, opening multiple independent windows of one application, moving, resizing from both lower corners and three edges, snapping, focusing, minimizing into per-window sidebar entries, restoring, shrinking to each application's minimum size, pinning, Delete-key cleanup, closing, arranging, and locally saving application windows. Full-screen windows are deliberately absent so the desk always reads as overlapping work, and the redundant bottom shelf has been removed in favor of the application and minimized-window sidebar. The System Designer treats its darker grid as a fixed 1800×1200 design world viewed through a resizable camera with arrow-key panning and stepped zoom; the Designer and its component palette are raised while every supporting app lies flat like paperwork. Its component controls are horizontal rectangles with the pixel beside a visible name for Sand, Wall, Input, and Output. The component palette starts as its own window joined flush to the Designer on one shared focus layer, with no inner shadow or link controls visible. The joined pair stops at the desktop edge without changing the palette's chosen side. Dragging the palette away exposes small matching outward redock arrows on both windows; either arrow reunites the pair without losing the selected component. The Manual app renders the real nineteen-page HCW-7 operator reference with a bundled PDF.js viewer and can open another local PDF without replacing the window. The Contract Board leads HC-001's detail view with its $30 maximum cost and 20×20 maximum frame, followed by the I/O, test, and difficulty details. HC-001 fixes a free Input in the frame's top-left corner and a free Output in its top-right corner, runs 500 turns with Input on followed by 500 with it off, then reports efficiency (Sand out divided by Sand in), speed (Sand out divided by elapsed turns), price, and the bounding-rectangle area of the whole machine. Sand and Wall cost $1 each. Its download control delivers a real ZIP containing matching materials and requirements PDFs plus a starter HCW save with the same limits and fixed ports, while importing the same package into the in-workspace Files app without duplicating it on repeated downloads. Contract PDFs open in the real PDF viewer from Files. The Files app also supports named folder creation, nested navigation, and drag-and-drop organization across folders and breadcrumbs. Pinned windows survive the Delete cleanup, while Delete remains available inside text fields. Placeholder Designer, Trace, Notes, and Archive applications establish the remaining spatial relationships. Version 6 local snapshots preserve file organization, contract imports, palette ownership, and docking state alongside the rest of the workspace. `WorkspaceBridge` exposes a small topic-based event surface for later window-to-window behavior.

Visit the published GitHub Pages build. A local checkout should be served through a small static web server so the bundled PDF worker can load the manual.
