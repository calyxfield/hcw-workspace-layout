# HCW Workspace Layout Prototype

A standalone layout study for the cellular-automata factory game's pseudo-desktop.

It deliberately tests the workspace shell before the game is coupled into it: launching, opening multiple independent windows of one application, moving, resizing from both lower corners and three edges, snapping, focusing, minimizing into per-window sidebar entries, restoring, shrinking to each application's minimum size, pinning, Delete-key cleanup, closing, arranging, and locally saving application windows. Full-screen windows are deliberately absent so the desk always reads as overlapping work. The System Designer treats its grid as a fixed 1800×1200 design world viewed through a resizable camera with arrow-key panning and stepped zoom. Its square component buttons expose their names on hover. The component palette starts as its own window joined flush to the Designer with no link controls visible. Dragging it away exposes matching outward redock arrows on both windows; either arrow reunites the pair without losing the selected component. Pinned windows survive the Delete cleanup, while Delete remains available inside text fields. Placeholder Designer, Manual, Contract, Trace, Notes, and Archive applications establish the intended spatial relationships. Version 5 local snapshots preserve palette ownership and docking state alongside the rest of the workspace. `WorkspaceBridge` exposes a small topic-based event surface for later window-to-window behavior.
