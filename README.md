# HCW Workspace Layout Prototype

A standalone layout study for the cellular-automata factory game's pseudo-desktop.

It deliberately tests the workspace shell before the game is coupled into it: launching, opening multiple independent windows of one application, moving, resizing from both lower corners and three edges, snapping, focusing, minimizing into per-window sidebar entries, restoring, shrinking to each application's minimum size, pinning, Delete-key cleanup, closing, arranging, and locally saving application windows. Full-screen windows are deliberately absent so the desk always reads as overlapping work. The System Designer is the only raised window and treats its darker grid as a fixed 1800×1200 design world viewed through a resizable camera with arrow-key panning and stepped zoom; every supporting app lies flat like paperwork. Its square component buttons expose their names on hover. The component palette starts as its own window joined flush to the Designer on one shared focus layer, with no inner shadow or link controls visible. Dragging it away exposes small matching outward redock arrows on both windows; either arrow reunites the pair without losing the selected component. The Files app supports named folder creation, nested navigation, and drag-and-drop organization across folders and breadcrumbs. Pinned windows survive the Delete cleanup, while Delete remains available inside text fields. Placeholder Designer, Manual, Contract, Trace, Notes, Files, and Archive applications establish the intended spatial relationships. Version 6 local snapshots preserve file organization, palette ownership, and docking state alongside the rest of the workspace. `WorkspaceBridge` exposes a small topic-based event surface for later window-to-window behavior.
